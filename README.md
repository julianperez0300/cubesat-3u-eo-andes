# CubeSat 3U de observación de la Tierra (RGB + NIR)

Diseño y simulación de un CubeSat 3U en órbita heliosíncrona (~550 km)
para monitoreo de cobertura vegetal y deforestación en Colombia
y la región andina.

## Estado

Fase 0: preparación

## Estructura del repositorio

- `docs/`: documentación y registro de decisiones
- `requisitos/`: requisitos de misión y de sistema
- `simulacion/`: modelos por subsistema y modelo integrado
- `cad/`: estructura y distribución interna
- `presupuestos/`: masa, potencia, datos y enlace
- `referencias/`: papers, datasheets y notas de lectura
